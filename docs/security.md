# Threat model

| Risk                            | Control and remaining trust                                                                                                                                                                                                                                                                        |
|---------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Subscription URL leakage        | 32 random bytes, hashed at rest, constant-time comparison, revocation, expiration, bounded rotation grace. Treat client history, screenshots, QR images and clipboard as secrets.                                                                                                                  |
| Unauthorised HTTP access        | Strict host, fixed method and segment count, exact token and format, cache prevention, no static credential tree, loopback publisher, TLS-only Nginx frontend. The publisher caps aggregate requests per minute, headers, read/write time and request bodies. A flood can deny legitimate clients. |
| Access logs                     | Dedicated Nginx and publisher omit request logging. Cloud, client and external monitoring logs remain under operator control.                                                                                                                                                                      |
| Credential exposure             | Private generation directories, 0600 files, no secrets in status, dynamic users, systemd credentials. A compromised host root can recover secrets. Protocol credentials survive subscription revocation; disable affected nodes or reprovision if actual node secrets leaked.                      |
| Binary supply chain             | Initial official releases have pinned artifact digests. Stable updates validate GitHub digest metadata or an operator-provided trusted hash. Release-account and build-toolchain compromise remain trust boundaries.                                                                               |
| Malicious rules                 | Pinned digests, bounded reads, typed rules, constrained group/host/CIDR syntax and rollback. Untrusted local backups should never be restored.                                                                                                                                                     |
| Cloudflare token compromise     | Scoped token in a private file, sanitized API errors, IDs checked before mutations, explicit conflict confirmation. Revoke at the provider after disclosure.                                                                                                                                       |
| Command injection and traversal | Argument-vector execution, constrained hostnames, protocol IDs and generated paths. External configuration is serialized with JSON/YAML encoders.                                                                                                                                                  |
| Interrupted upgrade             | Private staging, real configuration validation, generation switch, persisted rollback journal, PID-owned socket checks. Retain independent backups for disk loss.                                                                                                                                  |
| DNS leakage                     | Explicit proxy resolver, encrypted bootstrap exception, separate strict and balanced profiles. Inspect OS, IPv6 and browser behavior on actual clients.                                                                                                                                            |
| Unauthorised service use        | Authenticated protocol inbounds, private WS origins, no public control interface. Holders of valid proxy credentials can use the VPS network; restrict sensitive destinations with site network policy where needed.                                                                               |
